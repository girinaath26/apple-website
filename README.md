# Apple Website

A front-end practice project inspired by Apple's website.

## Technologies Used

- HTML
- CSS
- JavaScript

## About the Project

This project recreates the look and navigation of an Apple-style website.
It includes multiple pages connected through a common navigation structure,
with shared styling, JavaScript functionality, and image assets.

The project was developed with AI assistance and customized and organized
for my learning and practice.

## What I Practiced

- Creating multi-page websites using HTML
- Styling pages with CSS
- Connecting multiple pages through navigation
- Using JavaScript for website functionality
- Organizing website assets and files

## Note

This is a learning/practice project and is not affiliated with Apple Inc.
